#   pip install -r requirements.txt

# Versions are pinned for reproducibility. Every pin below was checked to

# 3.11 and 3.13 on every push, so a bad bump fails there rather than on

# NOTE: LLM reasoning runs through the user's own agent CLI as a subprocess
# (see api/agent/), on their subscription. That is why neither the `anthropic`
# package nor an ANTHROPIC_API_KEY appears here, and why adding one would be a
# design error rather than a convenience (DECISIONS #10). Everything in core/
# is deterministic Python.
